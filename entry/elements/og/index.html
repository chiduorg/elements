第七层结束：鿫与 5f6d7s7p 闭壳

Closed shell 118: oganesson and the predicted filled 7s7p

来源已核对·开放知识条目

鿫是周期表目前的最后一个格子。按填充规则，7s 与 7p 应当填满，但它的构型与性质全部来自计算预测；已有实验只确认它极不稳定，半衰期以毫秒计。

这一层在哪里结束

第七周期的填充次序是 7s→5f→6d→7p。钫、镭占 7s，锕到锘补 5f，铹到鎶补 6d，鉨到鿫补 7p。[1] 按这套规则，鿫的构型应为 [Rn]5f¹⁴6d¹⁰7s²7p⁶，七个能层全部填满，看起来是完美的第八个闭壳。但这里必须踩刹车：118 号元素至今只合成出极少数原子，没有任何光谱数据能直接验证它的基态构型，上述排布是相对论计算结果。[2]

下一层为什么从这里开始

严格说，这里没有“下一层”。周期表的第七周期在鿫处用完了现有的 7p 容量，若继续填入，电子将进入 8s，而 8s 及以后的元素尚未被合成。[1] 更值得注意的是，相对论效应在 Z=118 时非常强：7s 与 7p 的能级被显著重排，理论计算甚至预测鿫的电子亲和能和极化率会偏离“惰性气体”的直觉。闭壳的规律仍然成立，但它的化学后果可能与氦、氖完全不同。

相对 Z−1：六项差值

  • 第一电离能：鿫与鿬都没有实验值，只能给理论预测，不能写“升高多少”。[2]
  • 原子半径：两者都无公认实验半径；计算值口径不同，本页不给差值。[2]
  • 电负性：两者都无公认 Pauling 电负性，差值未知。[2]
  • 价电子构型：7s²7p⁵ → 7s²7p⁶，按预测 7p 闭壳，但未经光谱验证。[1]
  • N/Z：²⁹⁴Og 为 176/118≈1.492，²⁹⁴Ts 为 177/117≈1.513，下降约 0.021；两者都无稳定同位素。[3]
  • 核来源：两者都由人工重离子轰击合成，不来自恒星核合成。[1]

这些元素从哪里来

鿫不是天然存在的元素，也不来自恒星核合成。它由实验室用较重离子轰击锕系靶核合成，每次只产生几个原子，靠衰变链的α粒子能量来识别。[1] 同样的方法产出了 104 号以后的绝大多数元素。把它们放进元素轴，并不是说它们在宇宙中常见，而是说周期表的结构允许它们存在。来源页会说明人工合成与宇宙核合成的边界，这一页只负责标出终点。

怎么用这个节点继续走

往上是氡，这一页之后没有下一个闭壳节点。想弄清为什么超重元素的预测值必须与实测分开，去看核稳定性解释页；想弄清周期表的边界是物理限制还是观测限制，去看周期律解释页；想弄清相对论效应如何改写重元素性质，去看镧系收缩解释页——同样的机制在 Z=118 被放大。把鿫当作一个警告标志：规律能推到多远，取决于我们能否验证它。

适用条件与比较口径

  • 鿫的电子构型、电离能与化学性质均来自理论计算，尚无实验测定；本页把预测值与实测值严格分开，不把 7p⁶ 当作已观测事实。
