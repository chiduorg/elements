锗：第 32 个质子把 4p 加到两个，第四周期开始向共价倾斜

Germanium

来源已核对·开放知识条目

镓的 4p1 变成 4p2，3d10 与 4s2 保持完整；电离能跳升 1.899 eV、电负性到 2.01，锗站到金属与类金属的交界。

第 32 个质子把电子放进了哪里

镓的价层是 3d10 4s2 4p1，锗多出的电子继续进入 4p，构型为 [Ar] 3d10 4s2 4p2。[1] 4p 亚层开始积累，但离半满还差一个、离全满差四个；4s2 与 3d10 都保持完整。这一步没有换层，也没有换亚层，变化只是同一个 4p 里从一加到二。

变化虽小，方向却明确：4p 电子越多，价层越难整体交出，元素越往共价一侧靠。锗正处在镓与砷之间的过渡位置，4p2 恰好让它既保留四价的可能性，又开始具备方向性成键的条件。第四周期 p 区的性格分界，就在这一格附近发生。

相对 Z−1：六项差值

  • 第一电离能：锗 7.898 eV，镓 5.999 eV，增大 1.899 eV。[1]
  • 原子半径：锗 125 pm，镓 136 pm，减小 11 pm（计算值口径）。[1]
  • 电负性：锗 2.01，镓 1.81，增大 0.20。[1]
  • 价电子构型：镓为 3d10 4s2 4p1，锗为 3d10 4s2 4p2；新增电子进入 4p，亚层未换。
  • N/Z：锗-73 有 41 个中子，N/Z 为 1.28；镓-70 有 39 个中子，N/Z 为 1.26；中子加 2。锗有稳定同位素。[2]
  • 核来源：锗记作“s 过程与 r 过程”，镓记作“s 过程（AGB 星）与超新星”；锗把快中子俘获明确写进了来源。

电离能跳升 1.899 eV，与镓那一格 3.395 eV 的下跌正好构成一对：4p 从 1 到 2，等于在同一个亚层里增加一个电子，核电荷增加的吸引不再被“换轨道”稀释，所以束缚明显变紧。半径收缩 11 pm，也是这一带较大的幅度。电负性 2.01 让锗越过 2.00，正式落在类金属一侧；这三个数指向同一件事：p 电子累积到第二个时，性格开始翻转。

为什么这一格重要

4p2 让锗的价电子数与碳相同，都是四，但两者的成键环境完全不同：碳只有 2p，锗的价层外面还压着 3d10，半径大得多，4p 轨道也更弥散。[1] 结果是同一族、同一价电子数，碳搭出稳定的多重键与网络，锗却更倾向单键与四面体配位，电负性 2.01 也正好卡在金属与非金属之间。这一格的价值在于它证明“价电子数相同”远不足以预测化学，内层结构与半径同样在起作用。

它从哪里来

来源条目记作“s 过程与 r 过程”。s 过程在 AGB 星里慢速推进，r 过程则在剧烈环境中快速俘获中子，两条路径都能产出锗；质量数 73 附近是两者都能到达的区间。[2] 挂到时间轴上，s 过程对应低质量恒星晚期，r 过程对应超新星或中子星并合这类事件。锗之所以被两条路径共同覆盖，是因为它的质量数不大不小，恰好落在两条路径的重叠带上；这也让它的丰度对单一事件的依赖较弱。

怎么继续走

往回是镓（/entry/elements/ga/），能看到 4p1 如何把 d 区拉回 p 区；往前是砷（/entry/elements/as/），4p3 半满后类金属性格进一步固化。想把 4p 与 3d10 的相对位置读清楚，去读电子排布解释页；想把 s 与 r 两条路径分开，去读重元素富集节点。

适用条件与比较口径

  • 标准状态（298 K，1 bar）下的中性气态原子；电离能与半径均为孤立原子口径。

元素 / 解释层

电子排布：为什么顺序是 1s→2s→2p→3s→3p→4s→3d

元素的性质不是按质子数平铺，而是按电子填入的次序分段。这一页解释 Aufbau 次序、4s 与 3d 的交错，以及铬、铜、钆、铂为什么是例外。
